# Скриншоты и логи демо

Папка для материалов «Примеры обработки запросов: скриншоты или логи» (п. 04 формата результатов).

- `chat_log.json` — массив реальных ответов `/chat` (запросы из `docs/demo_cases.md`), собранный
  скриптом `examples/capture_demo_logs.ps1`. Генерируется при запущенном сервисе:

  ```powershell
  docker compose up --build
  .\examples\capture_demo_logs.ps1
  ```

- Скриншоты/PNG диалога можно класть в эту папку и при желании подключать в README.

> В репозитории хранятся только файлы, созданные описанным выше скриптом или вручную при
> реальном прогоне (демонстрация жюри). Собирать логи следует на том же стенде, где работает
> сервис с моделями (`chromadb` + Ollama), — локальная среда моделей не грузит.
